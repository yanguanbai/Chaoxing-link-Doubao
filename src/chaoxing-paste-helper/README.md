# 学习通强制纯文本粘贴助手

当前版本：`1.2.1` · 作者：Bart · [English](README.en.md)

学习通简答题编辑器的粘贴辅助脚本。剪贴板里有图片时走原生粘贴，只有文字时转成编辑器可处理的纯文本并保留换行。

## 功能

- 在学习通页面的 UEditor 实例上接管粘贴事件。
- 读剪贴板，含图片时放行，不干扰图片题。
- 只有文本时按换行拆段，以纯文本方式写入编辑器，避免带入网页样式或丢失段落。

## 安装

1. 安装并启用 Tampermonkey。
2. 点击根目录 README 中“纯文本粘贴助手”的安装链接并确认。
3. 刷新学习通页面。

这是独立的第二个脚本，主脚本不包含它的代码；不装不影响主脚本启动，只影响简答题的文字录入。

## 限制

- 仅处理学习通页面内可访问的 UEditor 实例，其它编辑器不处理。
- 依赖页面已加载 `UE`（UEditor），实例尚未创建时不会生效，刷新后重新识别。
- 效果取决于浏览器对剪贴板 API 的实现与权限；无权限读取剪贴板时按原生粘贴处理。

## 常见问题

**粘贴没反应或样式照旧**：确认脚本已启用、当前页面有 UEditor 实例，并刷新页面重试。

**图片粘贴失效**：说明脚本把图片也当文本处理了，确认装的是本仓库这一版，而不是旧版单一逻辑的副本。

## 版本与维护

版本号以脚本头 `@version` 为准，逐版本变更见仓库根目录的 [CHANGELOG.md](../../CHANGELOG.md)。
