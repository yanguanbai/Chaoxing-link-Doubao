# 学习通豆包助手

当前版本：`1.6.3` · 作者：Bart · [English](README.en.md)

在学习通答题页面提取当前题目，交给豆包网页端辅助分析，再把结果回填到页面。脚本同时运行在学习通页和豆包页：前者取题与回填，后者把题目送进对话并把回复交回，两端通过脚本管理器的跨标签存储通信。

## 功能

- **作业页**逐题拼装题目：只取题干与选项，题量、满分、作答时间、答题卡等页面信息不会发给豆包；截图也只渲染题目块。
- **考试页**只读取当前可见题目，避免把考试导航、题号卡片一起发出。
- 两种发送方式：发送题目文字，或把题目渲染成截图上传，适配公式与图片题。
- 「打开豆包」点一次就打开绑定的对话页（仅 2 秒防连点），不做页面是否已打开的检测。
- 绑定为手动：在豆包面板点「绑定本页」登记为专属页，「解除绑定」红色按钮清除；本页与绑定记录一致时状态显示绿色“该页面已绑定”，否则显示“未绑定”。
- 绑定按标签页识别：豆包换到 `/chat/<id>` 会话后绑定仍然有效；没有绑定记录时学习通端不会发送，提示先去豆包面板绑定。
- 发送状态会回传：已接收、已完成、失败、超时在面板上分别提示，不再一直停在“已发送”。
- 解析豆包回复中的 JSON，按题型把选项写回页面；也可在豆包面板手动抓取。
- 豆包面板三个按钮平铺：手动抓取、绑定本页、解除绑定。
- `跳过已答题目` 的状态会保存；`自动下一题` 只在考试页出现并生效，作业页整页发送后不再翻页。
- 判断题按页面实际选项输出：页面显示“正确/错误”返回文字，显示“A/B”返回字母。

## 安装

1. 安装并启用 Tampermonkey，允许它在网页上运行脚本。
2. 点击根目录 README 中的安装链接并确认。
3. 刷新学习通答题页面。

> [!IMPORTANT]
> **要用截图功能就必须装好并启用 Disable Content-Security-Policy 扩展。**
> 学习通页面的 CSP 会拦下脚本从 jsDelivr 加载的 `html2canvas` 和画布导出，不启用时截图失败；文字发送与跨页面通信不受影响。装完点扩展图标确认启用，并按标签页保持启用态。

> [!IMPORTANT]
> 简答题需要配套的[纯文本粘贴助手](../chaoxing-paste-helper/README.md)，它是必须单独安装的第二个脚本。只装本脚本时简答题无法正常录入，整体不能正常使用。

## 使用

1. 打开豆包并登录，进到要答题用的对话页，在豆包面板点「绑定本页」；状态变绿即绑定成功。
2. 打开学习通答题页，点“初始化规则”。
3. 按题型点“发送文字”或“发送截图”。豆包页未运行时，脚本先存消息再打开页面。
4. 豆包回复后自动抓取回传，也可手动抓取。
5. 作业页一次发送整页、批量回填后结束；考试页一题一发送，需要连续作答时打开“自动下一题”。

## 支持页面

| 页面 | 功能 |
|---|---|
| `*.chaoxing.com/mooc-ans*` | 取题、发送、回填 |
| `*.chaoxing.com/exam-ans*` | 取题、发送、回填 |
| `*.doubao.com/*` | 接收题目、抓取回复、页面绑定 |

页面匹配只代表脚本会在该地址运行，不代表该页面的每种题目布局都能识别。页面改版后，题目定位与回填需要重新适配。

## 兼容与依赖

- 脚本管理器：Tampermonkey。仅在此扩展上验证，其它管理器未测试。
- 截图：`html2canvas`（经 jsDelivr 按固定版本加载）加 Disable Content-Security-Policy 扩展。
- `@noframes`，不在 iframe 内运行；题目页面若被嵌在子框架里，脚本不会生效。
- 判断题、填空题、选择题按页面实际选项回填；无法识别的题型跳过。

## 隐私与数据安全

题目与答案经脚本管理器的跨标签存储传递，页面绑定与开关设置保存在同一处；项目没有自建服务器收集题目或账号。点击发送后，题目文字或截图进入豆包网页对话，由豆包平台按其规则处理。截图在浏览器本地由 canvas 生成并经豆包页面上传，不经过第三方图床。卸载扩展或清除扩展数据会丢失绑定与设置。

## 常见问题

**面板不出现**：确认 Tampermonkey 已启用、允许在网页运行脚本，且当前页面属于上表地址。

**出现两个面板**：同一脚本装了两份，脚本列表里删掉多余那条。

**截图失败**：按顺序查——CSP 扩展是否装并启用 → 刷新学习通页面 → jsDelivr 是否可达 → 题干图片跨域无 CORS（改用“发送文字”）。

**答案错位或重复发送**：确认只启用了一个脚本实例、只绑定了一个豆包标签页；作业页按题目顺序对齐答案，手动切题后建议重新发送。

**面板显示“豆包未响应”**：确认绑定的豆包标签页还开着；若换了标签页或对话，在豆包面板点「绑定本页」后再发一次。

## 版本与维护

版本号以脚本头 `@version` 为准，逐版本变更见仓库根目录的 [CHANGELOG.md](../../CHANGELOG.md)。覆盖安装会保留绑定与开关设置；不要同时启用同一脚本的多个副本。
